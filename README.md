# DailyManager

A premium, dark, responsive workspace for tasks, projects, notes and day-to-day management.

## Stack
- Next.js 14 App Router
- React 18
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

## Current implementation status

The first UI foundation includes a responsive dashboard, sidebar navigation, overview cards, weekly activity visualization, task completion interactions and a create-task modal. Task data is currently held in browser memory and resets on refresh. Authentication, Neon persistence, team features, calendar data, billing and production integrations are not yet implemented. Demo metrics are illustrative, not live business data.

## Deploy
Connect this repository to the existing `dailymanager` Vercel project. Verify the build and configure required environment variables before enabling production data or authentication.
